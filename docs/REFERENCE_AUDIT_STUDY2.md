## 5. Cara Import ke Mendeley

1. Buka Mendeley Reference Manager, pilih **Add new → DOI**.
2. Untuk 28 referensi ber-DOI Crossref, tempel DOI dari tabel di atas.
3. Untuk arXiv (Kingma & Ba, Bouthillier et al.), gunakan URL arXiv, bukan DOI Crossref.
4. Untuk buku dan dokumentasi daring (López de Prado, Binance, Optuna, TensorFlow), input manual.
5. Setelah import, cek tahun sesuai catatan di Bagian 2.
6. Baru lakukan **Insert Citation** di Word. Sitasi teks lama jangan dibiarkan.
