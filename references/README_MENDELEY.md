### Langkah-langkah di Mendeley Reference Manager / Mendeley Desktop

1. Buka aplikasi **Mendeley**.
2. Buat koleksi baru bernama `Skripsi_Study2_Volatilitas`.
3. Klik **Add new** (atau menu `File` → `Import...`).
4. Pilih format **RIS (*.ris)** atau **BibTeX (*.bib)**.
5. Arahkan ke `D:\OneDrive\Desktop\jurnal\references\study2_references.ris`.
6. Pastikan jumlah entri yang masuk **36**, bukan 35 atau 32.
7. Setelah impor, cek tahun terbit pada tabel catatan di Bagian 5 (Corsi, Christensen, Kingma, Wahyuddin).
