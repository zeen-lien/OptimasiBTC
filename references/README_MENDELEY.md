## 1. Cara Cepat Impor Seluruh Referensi (1 Menit)

Kami telah menyiapkan berkas ekspor standar bibliografi yang memuat seluruh metadata terverifikasi (penulis, judul, jurnal, tahun, volume, issue, halaman, DOI, URL):

- **Format RIS:** `references/study2_references.ris` *(Paling direkomendasikan untuk Mendeley)*
- **Format BibTeX:** `references/study2_references.bib`

### Langkah-langkah di Mendeley Reference Manager / Mendeley Desktop:
1. Buka aplikasi **Mendeley**.
2. Buat folder/koleksi baru bernama: `Skripsi_Study2_Volatilitas`.
3. Klik tombol **Add new** (atau menu `File` -> `Import...`).
4. Pilih opsi **RIS (*.ris)** atau **BibTeX (*.bib)**.
5. Arahkan ke berkas: `D:\OneDrive\Desktop\jurnal\references\study2_references.ris`.
6. Seluruh **35 entri referensi** akan langsung masuk secara otomatis dengan metadata yang lengkap, rapi, dan sesuai standar sitasi APA 7th Edition.
